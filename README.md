# Auto-Petition
A discord bot that handles petition creation and voting on the CozyMC server

The DISCORD_TOKEN in .env needs to be set after setting up the basic bot on discord's developer website. Libraries in requirements.txt need to also be installed.

Channel IDs in main.py should be defined as:
PETITIONS_CHANNEL_ID = 1462204507269238804
VOTES_CHANNEL_ID = 1389992532967948369
